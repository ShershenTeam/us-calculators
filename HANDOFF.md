# Почни тут: проєкт «Сайт калькуляторів для США»

Цей документ пояснює людині, яка відкриває проєкт уперше, що це за проєкт, що вже зроблено, які рішення прийнято і чому, що робити далі. Складено 28.09.2026 за підсумками робочого чату власника проєкту з AI-асистентом (Claude Code).

## 1. Що це за проєкт (коротко)

Ми плануємо **сайт онлайн-калькуляторів для США**, який отримує відвідувачів з пошуку Google і заробляє на рекламі:
- калькулятори: табель робочих годин, гравій, бетон, відсотки тощо;
- конвертери одиниць: фунти ↔ кілограми, °C ↔ °F;
- швидкі відповіді: «яка дата буде через 90 днів».

**Головні параметри:**
- **Ринок:** США. **Мова:** англійська. Іспанська — пізніше і вибірково.
- **Сайт статичний.** Готові HTML-сторінки, без бази даних. Розробка в GitHub, розміщення на власному сервері або в Cloudflare.
- **Масштаб:** ~143 сторінки на запуску → ~1 020 за рік (поіменний список уже є).

**Стан на 28.09.2026:** зроблено дослідження, стратегію, архітектуру й поіменний план сторінок. **Коду сайту ще немає.** Не створено репозиторій і не куплено домен.

## 3. Як ми дійшли до поточного плану (історія обговорення)

### 3.1. Звідки взялась ідея
- **6.08.2026** власник у старому акаунті Claude (режим Cowork) спитав, чи запускати набір калькуляторів «на всі мови світу». Відповідь: ні. Спершу одна мова якісно, потім 3–5 мов за формулою «обсяг пошуку × дохід з реклами ÷ конкуренція». Текст цього чату відновлено: `research/old-chat-calculators-all-languages.md`.
- **Того ж дня** власник вивантажив з Ubersuggest 434 пошукові запити зі словом «calculator» (США) і отримав їх аналіз у таблиці `US_calculator_keyword_analysis_full.xlsx`: 103 ідеї калькуляторів, пріоритети. `notes.docx` — короткий опис цієї таблиці.

### 3.2. Постановка задачі (27.09.2026)
Власник попросив:
1. визначити, якими мовами робити сайт;
2. продумати, як сайт виглядатиме для користувача: меню, архітектура, перелінковка, SEO-текст на сторінках;
3. перевірити в Google, які конкуренти є по кожному калькулятору, їхні сильні сторони, і як зробити краще;
4. обрати технології, на яких будувати сайт і калькулятори, щоб легко додавати нові;
5. вести розробку в GitHub зі спільним доступом і деплоїти статичний сайт на сервер.

### 3.3. Як збирали дані
- Потрібна була **справжня видача Google США.** Власник наголосив: сайт просуватимемо через Google, тож дивимось лише Google.
- Спробували кілька джерел:
  - **Tavily** — вичерпав ліміт;
  - **Google і Bing у вбудованому браузері** — видають неправдиві результати (сторонні сайти, казино), бо запити йдуть не з США;
  - **Serper.dev** — скрипт підготовлено, але не використовували.
- Власник підключив **Ubersuggest** (через конектор акаунта claude.ai). З нього зібрали:
  - реальні обсяги пошуку ~100 запитів;
  - топ-10 Google по 56 запитах з силою сайтів;
  - топ-сторінки 10 конкурентів — 4 006 сторінок.

  Усі дані збережено в `research/`.

### 3.4. Ключові відкриття
1. **Цифри в початковому Excel спотворені.** Він будувався на хвостах запитів («calculator 30 percent off»), а не на головних («percent off calculator»). Наприклад, складність percent off насправді 36, а не 4. Пріоритети перераховано.
2. **Google пускає нові сайти в топ:**
   - «time duration calculator» (135 тис. пошуків/міс): увесь топ-10 — сайти з силою DA 1–10;
   - «texas paycheck calculator»: №1 має сайт із DA 3.
3. **Найбільше трафіку в ніші дають не складні калькулятори, а:**
   - конвертери одиниць: «ounces to pounds» у rapidtables — ~8,8 млн відвідувань/міс;
   - сторінки конкретних значень: «80 kg to lbs» — ~1 млн, «5'7" in cm» — ~550 тис.;
   - відповіді про дати: «90 days from today», «how many weeks in a year».

   Посилань на такі сторінки майже немає, тож новому сайту їх отримати найлегше.
4. **Зарплатні калькулятори по штатах** («Texas paycheck calculator») — найдорожча реклама в ніші (CPC до $21), а в топі там нові слабкі сайти.
5. **Фінанси й здоров'я** — сфери «YMYL»: Google вимагає експертизи, видачу тримають банки й держсайти. Туди заходимо пізніше і з фахівцем-рецензентом.
6. **Іспанська:** калькулятори іспанською в США майже не шукають (іпотека — 480/міс проти 2,7 млн англійською). Зате шукають конвертери з американських одиниць («libras a kilos» — 135 тис.) і курс долара до песо (368 тис.). Отже, іспанська — лише вибірковий набір сторінок.
7. **Лідери ніші втрачають трафік:** calculator.net −70% за рік, omnicalculator −54%. Причина — AI-відповіді Google і оновлення алгоритмів. Виграють сторінки з реальною користю (таблиці, друк, збереження, пояснення), а не «голий» віджет.

## 8. Як продовжити роботу з AI-асистентом на іншому ПК

1. Встановити Claude Code (застосунок Claude Desktop → вкладка Code, або CLI `claude`).
2. Відкрити сесію в папці проєкту. Асистент прочитає `CLAUDE.md` і правила.

   > **Якщо у вас уже є свій CLAUDE.md:**
   > - особистий файл (`~/.claude/CLAUDE.md`) діє в усіх ваших проєктах;
   > - проєктний `CLAUDE.md` діє лише в цій папці;
   > - у цій папці асистент бачить обидва файли, і вони не перезаписують один одного.
   >
   > Проєктний файл містить лише правила цього сайту. Переконайтеся, що в особистому немає прямих суперечностей (наприклад, іншої мови відповідей). Особисті вподобання тримайте у своєму файлі, а не в проєктному. Не кладіть папку проєкту всередину іншого репозиторію з власним CLAUDE.md: файли з батьківських папок теж підхоплюються.
3. Приклади запитів:
   - «Прочитай HANDOFF.md і коротко скажи, на чому ми зупинились»;
   - «Створи репозиторій і каркас сайту за docs/04»;
   - «Зроби бриф і сторінку для gravel calculator за docs/09»;
   - «Онови Page_Plan: gravel calculator опубліковано».

Щоб перезібрати план сторінок після змін у правилах (без нових даних):
```bash
python research/build_inventory.py
```
```bash
python research/export_plan.py
```
Потрібні Python 3 і бібліотека `openpyxl` (`pip install openpyxl`).

## 9. Словник

| Термін | Що означає |
|---|---|
| **SERP / видача** | Сторінка результатів пошуку Google |
| **Обсяг** | Скільки разів на місяць запит шукають у Google США |
| **SD** (SEO difficulty) | Складність потрапити в топ за запитом, 0–100 (оцінка Ubersuggest) |
| **DA** (Domain Authority) | Сила сайту, 0–100. Новий сайт — 0–10 |
| **Донори / ref. domains** | Скільки різних сайтів посилаються на сторінку. Більше = сильніша сторінка |
| **CPC** | Скільки рекламодавці платять за клік за цим запитом. Показує, наскільки дорогою буде реклама на сторінці |
| **YMYL** | «Your Money or Your Life» — фінанси, здоров'я. Google вимагає підтвердженої експертизи |
| **E-E-A-T** | Досвід, експертиза, авторитетність, довіра — те, як Google оцінює якість контенту |
| **Хаб** | Сторінка категорії зі списком її калькуляторів |
| **Сторінка значення** | Сторінка під конкретне число: «80 kg to lbs», «5'7" in cm» |
| **Бриф** | Документ-аналіз перед створенням сторінки (шаблон `docs/templates/page-brief.md`) |
| **Беклог** | Перевірені ідеї сторінок, відкладені на потім |
| **hreflang** | Розмітка, що пов'язує англійську й іспанську версії сторінки |
| **GSC** | Google Search Console — безкоштовний сервіс Google з реальними даними про покази й кліки сайту |
| **CI** | Автоматичні перевірки коду при кожній зміні (тести, SEO-правила, швидкість) |
| **Статичний сайт** | Сайт з готових HTML-файлів, без бази даних і серверного коду |
| **Dokploy** | Панель керування сервером, через яку власник уже розміщує свої сайти |
